# Clipora 0.1

Из одной съёмки делает много разных вертикальных роликов: расшифровывает речь, AI подбирает темы и варианты с разными хуками, сервер собирает видео с субтитрами, анализатор оригинальности проверяет каждый ролик перед выгрузкой.

Две папки:
- server — сервер на Dart (API, обработка видео, анализатор)
- app — приложение на Flutter (сайт с адаптацией под телефон и планшет, ставится как приложение)

## Первый запуск

### 1. Ключ Gemini
Зайди на aistudio.google.com, нажми Get API key → Create API key. Карта не нужна. Скопируй ключ.

### 2. Подготовка Mac (один раз)
В Терминале:

```
cd путь/к/clipora/server
bash scripts/setup_mac.sh
```

Скрипт поставит FFmpeg, whisper.cpp и chromaprint, скачает модель распознавания речи, создаст базу clipora и файл .env.

Открой файл server/.env и впиши ключ в строку GEMINI_API_KEY=

### 3. Запуск сервера
```
cd путь/к/clipora/server
dart pub get
dart run bin/server.dart
```
Должно появиться «Clipora API: http://localhost:8080». Окно не закрывай.

### 4. Запуск приложения
В новом окне Терминала:
```
cd путь/к/clipora/app
flutter create . --project-name clipora --platforms web,ios,android
flutter pub get
flutter run -d chrome --web-port 5173
```
Команда flutter create нужна только в первый раз: она доделает служебные папки, наши файлы не трогает.

Откроется Chrome. Зарегистрируйся, создай проект, загрузи видео.

## Как пользоваться
1. Исходники: загружаешь свои куски по 3–5 минут. Статус меняется сам: расшифровка → AI подбирает варианты → готово.
2. Варианты: карточки по темам, у каждой свой хук, длина и описание. Отмечаешь нужные, выбираешь стиль субтитров, жмёшь «Собрать».
3. Ролики: готовые видео с оценкой оригинальности. Выбираешь, куда выкладываешь (аккаунт 1, аккаунт 2, пробный рилс), и жмёшь «Выгрузить» — скачается mp4. Описание и хэштеги можно скопировать с карточки.
4. Музыку добавляешь сама в Instagram при публикации.

## Монтаж
Кнопка «Монтаж» на карточке варианта или в меню «…» готового ролика.

- Лента внизу — куски ролика по порядку. Фиолетовые — ваша речь, розовые — вставки.
- Нажми на кусок: обрезать ползунком (края прилипают к границам слов), разрезать в точке паузы, поменять местами, заменить, удалить.
- Перетаскивание кусков: зажми кусок на секунду и тяни (и на телефоне, и мышкой).
- «+» добавляет фразу из исходника, вставку из медиатеки, видео из галереи или съёмку камерой (на телефоне).
- «Вставка поверх голоса» — картинка сменяется вставкой, а голос продолжает звучать. Ставится в текущую точку плеера, потом двигается ползунком.
- Раздел «Вставки» в меню — медиатека кадров для перебивок. Длинное видео можно нарезать на куски по сменам плана автоматически, кускам можно ставить метки.
- Вставки сохраняются в медиатеку и доступны во всех роликах.
- Всё сохраняется само, есть «Отменить» и «Вернуть вариант AI».
- В браузере на стыках кусков бывают микропаузы. Точный результат показывает «Быстрое превью» — сервер собирает черновой ролик.
- Для монтажа сервер делает лёгкую копию каждого видео (540×960). У старых исходников она появится при первом открытии монтажа, это 1–2 минуты.

Аккаунты для выгрузки настраиваются кнопкой с ползунками в правом верхнем углу.

## Анализатор оригинальности
Проверяет ролик после сборки и ещё раз прямо перед выгрузкой. Сравнивает с исходником и со всеми уже выгруженными роликами.

- Монтаж: сколько склеек, переставлены ли фразы, нет ли одного длинного непрерывного куска.
- Сценарий: насколько совпадает текст с другими роликами, повторяется ли хук, начинается ли ролик теми же словами.
- Авторское: текст-хук на экране. Позже добавятся b-roll и озвучка. Фильтры, ускорение и зеркало баллов не дают специально.
- Почти копия: точная карта кусков исходника и отпечаток звука. Кадры не сравниваются: у говорящей головы они почти одинаковые и давали бы ложные срабатывания.

Светофор: зелёный — можно выгружать; жёлтый — есть подсказки, что поменять; красный — почти копия, выгрузка только после подтверждения.

## Если что-то не работает
- «Нет связи с сервером» — сервер не запущен или упал, посмотри окно Терминала с сервером.
- Gemini ответил 403 или «not available in your country» — нужен доступ через другую страну: впиши прокси в .env (HTTPS_PROXY=...).
- Gemini ответил 429 — закончились бесплатные запросы в минуту. Сервер сам подождёт и повторит.
- Ошибку из окна сервера можно просто прислать мне.
